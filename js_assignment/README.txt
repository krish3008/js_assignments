JavaScript Assignment — How to run

Files:
- welcome.html: Tasks 1, 2, 4 and 5 (welcome alert and console output).
- insta-bio.html: Tasks 3, 6, 7, 8, 9, 10, 11 and 12 (bio page, buttons, greeting, and green heading).

Run the assignment:
1. Extract this ZIP file.
2. Open the folder in VS Code.
3. (Recommended) Install the Live Server extension.
4. Right-click welcome.html or insta-bio.html and choose “Open with Live Server”.
   You can also double-click an HTML file to open it in your browser.
5. A welcome alert appears when the page loads. Click OK to continue.
6. For console messages, press F12 (or Ctrl+Shift+J in Chrome) and choose Console.

Before submitting:
- In insta-bio.html, replace [Your Name] with your own name.
- You may replace “Instagram” with your favorite app.
- The screenshot's tasks 1/2, 4/5, 7/8 and 10/11 are duplicates, so one working implementation covers each repeated task.
- Task 12: change the alert text to your own name, save the file, and refresh the Live Server page.

Learning notes:
- The <script> tag lets the browser run JavaScript in an HTML page.
- alert() displays a popup message.
- console.log() writes a message in DevTools Console.
- querySelector() selects an HTML element using a CSS selector.
- addEventListener("click", ...) runs code when a button is clicked.
- element.style.color changes an element's text color.
